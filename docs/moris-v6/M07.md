# M07 — Canonicalization and quality

The active Center and query paths both call `embedImageDinov2Variants` → Worker → `processLayer1Optical` → 224px pseudo-RGB → extractor. Legacy `imageCanonicalizer.js` is not an embedding caller (verified static references); its separate display transform must not label an embedding with the active contract.

## Changes

Removed segmentation's full-frame fallback for near-empty foreground. Empty masks fail with retake guidance. Bounded RGBA dimensions are validated before allocation. Added `mask_quality_v1` flags for insufficient/full-frame foreground, nonuniform border, touching edges and clipped foreground highlights. Flags are deterministic safety heuristics, not calibrated probabilities or curated mask labels.

Uniform scaling and letterbox now preserve aspect ratio instead of stretching every crop to square. Existing PCA and simultaneous 180-degree flip remain; padding is 6%. Changed preprocessing ID to `kim_canon_v3_letterbox` across browser/worker/server. Pseudo-RGB is CLAHE/Scharr/chamfer quantized to uint8 and passed once through the extractor processor; the separate normalized tensor utility is not normalized a second time by this path.
