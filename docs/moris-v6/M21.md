## Curator review workflow tooling and rejection schema

A dedicated curator CLI tool `tools/review-moris-hard-negatives.mjs` provides review operations:
- `--summary`: reports review queue status breakdown (approved, rejected, pending, tag breakdown, dev query links).
- `--list [--filter <status>]`: lists all cases with metadata/proposed counts.
- `--inspect <id>`: displays full case details, local image paths and development query ranking context.
- `--export-html`: generates standalone offline HTML review sheet (`evaluation/moris-v6/hard-negative-review-sheet.html`) for visual review by human curators against local catalogue images.
- `--record-reject`: records dismissal of false alarms with curator name, timestamp, and rejection reason.
- `--record-approve`: records approval with strict image hash and before/after ranking snapshot SHA-256 validation.
