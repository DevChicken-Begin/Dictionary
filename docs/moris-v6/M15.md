# M15 — Experimental contour verifier; acceptance pending

Implemented a bounded 64-point equal-arclength contour plus existing 16 EFD amplitudes. Normalization uses uniform scale and PCA rotation, never implicit reflection; matching uses bidirectional Chamfer plus EFD distance under M13 transforms. Missing, malformed, degenerate or unreliable masks yield unavailable evidence. Worker attaches a compact query descriptor, not dense patches. No descriptor is persisted to cloud/index.

Main orchestrator has an explicit `contourVerification:false` feature gate; available evidence would enter the sole score owner. It remains OFF. Existing hydration only uses descriptors actually supplied by a compatible source, never derives them from IndexedDB or fabricates them from embeddings. Production RPC does not yet supply this field; missing evidence remains neutral.
